# QuantumMathCore

Quantum math core package extracted from KetSteps/QuatumPad.

## Local Development
- Open `Package.swift` in Xcode and run `QuantumMathCore-Package` tests on `My Mac`.

## Dependency Note
- Uses local path dependency to sibling package: `../ExactValueRecovery`.
- Keep the two repositories checked out as sibling folders when developing locally with path-based dependencies.

## GitHub Sync
- This directory is initialized as its own git repository.
- Add your own remote and push:
  - `git remote add origin <your-repo-url>`
  - `git push -u origin main`
